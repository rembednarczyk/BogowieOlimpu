# Rejestr źródeł

Każde źródło dostarczone przez autora projektu dostaje wpis. Reguły wydestylowane ze źródła trafiają do `10-REGULY.md` i odwołują się do jego identyfikatora.

## Format wpisu

```
### S-NNN: <krótki tytuł>
- Typ: dokument / strona WWW / wideo / zrzut ekranu / notatka autora / dane liczbowe
- Lokalizacja: <link lub ścieżka w repo, np. sources/S-NNN/>
- Dostarczone: RRRR-MM-DD
- Zakres: <czego dotyczy, np. ewolucja domów, chodziki>
- Wiarygodność: wysoka / średnia / niska (uzasadnienie)
- Wydestylowane reguły: R-NNN, R-NNN
- Notatki: <najważniejsze obserwacje>
```

Pliki źródłowe, które mają trafić do repo, przechowujemy w `sources/S-NNN/`. Materiały chronione prawem autorskim (np. zrzuty z gry referencyjnej, fragmenty podręczników) trzymamy wyłącznie jako materiał analityczny i nie wykorzystujemy w grze.

## Źródła

Brak. Czekamy na pierwszą partię od autora.
