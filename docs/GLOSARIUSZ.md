# Glosariusz

| Termin | Znaczenie |
|---|---|
| Spacerujący | Postać poruszająca się po drogach i wykonująca zadanie budynku, z którego wyszła. |
| Spacerujący losowy | Spacerujący bez celu, który obsługuje budynki mijane po drodze (np. nosiciel wody, sprzedawca z rynku). |
| Spacerujący celowy | Spacerujący zmierzający do konkretnego budynku (np. tragarz z towarem do magazynu). |
| Zasięg obsługi | Odległość od spacerującego, w której budynek zostaje obsłużony. |
| Ewolucja domu | Awans domu na wyższy poziom po spełnieniu wymagań; regres przy ich utracie. |
| Elita | Zamożni mieszkańcy rezydencji, źródło ciężkich jednostek wojskowych. |
| Atrakcyjność | Wartość kafla wynikająca z sąsiedztwa budynków, ozdób i terenu, wymagana przez wyższe poziomy domów. |
| Sanktuarium | Monument boga budowany etapami, warunek jego przychylności i wizyt. |
| Przychylność | Stosunek boga do miasta, od gniewu do łaski. |
| Heros | Postać mitologiczna przyzywana po spełnieniu warunków, walczy z potworami i wykonuje misje. |
| Potwór | Istota zsyłana przez boga lub obecna w scenariuszu, niszczy miasto do czasu pokonania. |
| Mapa świata | Strategiczna warstwa gry z innymi miastami, handlem, dyplomacją i wojną. |
| Tick | Jeden krok symulacji o stałej długości. |
| Nakładka | Tryb widoku pokazujący jedną warstwę informacji (np. zasięg wody). |
| Gra referencyjna | Zeus: Pan Olimpu z dodatkiem Posejdon, wzorzec mechanik gatunku. |
| S-NNN / R-NNN | Identyfikatory źródeł i reguł w dokumentacji. |
