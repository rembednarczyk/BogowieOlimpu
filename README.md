# Bogowie Olimpu

Strategiczny citybuilder w mitologii greckiej, projektowany od początku pod telefony (oraz tablety i PC). Mechanika rozgrywki odtwarza 1:1 grę Zeus: Pan Olimpu z dodatkiem Posejdon (R-001). Nazwy, grafika, dźwięk, teksty, mapy i kampanie tworzymy sami (R-002).

## Stan projektu

Faza 0: kontekst i reguły (specyfikacja gotowa). Następna: rozbudowa silnika na Godocie 4. Następne kroki: `docs/BACKLOG.md`.
