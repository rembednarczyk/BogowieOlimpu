# Bogowie Olimpu

Strategiczny citybuilder osadzony w mitologii greckiej, projektowany od początku pod telefony (oraz tablety i PC). Gra należy do gatunku klasycznych city-builderów z "chodzikami" i ewolucją domów, którego wzorcowym przedstawicielem jest Zeus: Pan Olimpu z dodatkiem Posejdon. Bogowie Olimpu bierze z tej gry głębię mechanik i rytm rozgrywki, a nazwy, grafikę, dźwięk, interfejs i kampanie tworzy samodzielnie.

## Stan projektu

Faza 0: zbieranie kontekstu, źródeł i reguł. Kod jeszcze nie powstał.
